Problem identified

The important part of your error is:


ReadError: not a gzip file

Your Python code is trying to open housing.tgz as a compressed TAR archive, but the file downloaded is not actually a gzip-compressed file.


One likely explanation is that GitHub has returned an HTML page instead of the dataset. This can happen when the download URL is incorrect or redirects unexpectedly.


There is another important detail: your code checks whether housing.tgz exists, but it does not check whether the existing file is valid. Therefore, an earlier failed download can remain in your datasets directory and cause the same error repeatedly.


1. Try this improved version

I recommend replacing your existing function with the following. It also deletes any previously downloaded invalid archive and downloads a fresh copy.



from pathlib import Path

import tarfile

import urllib.request

import pandas as pd


def load_housing_data():


# Define the dataset location

tarball_path = Path("datasets/housing.tgz")


# Create the datasets directory

Path("datasets").mkdir(parents=True, exist_ok=True)


# Download a fresh copy

url = "https://raw.githubusercontent.com/ageron/data/main/housing.tgz"


if tarball_path.exists():

tarball_path.unlink()


print("Downloading housing dataset...")


urllib.request.urlretrieve(url, tarball_path)


# Check whether the downloaded file is a valid archive

if not tarfile.is_tarfile(tarball_path):

raise ValueError("Downloaded file is not a valid TAR archive.")


# Extract the dataset

with tarfile.open(tarball_path, mode="r:gz") as housing_tarball:

housing_tarball.extractall(path="datasets", filter="data")


print("Dataset extracted successfully.")


# Load CSV into Pandas

return pd.read_csv("datasets/housing/housing.csv")
